# Aneesh U S — AI Architect & Machine Learning Engineer Portfolio

An interactive, production-engineered portfolio showcasing multimodal OCR pipelines, high-dimensional vector retrieval, quantitative deep learning engines, and full-stack cloud systems.

## Architectural Highlights

- **5-Act 3D Z-Axis Flight Engine (`InterstellarVoyager`)**: Inertial scroll-driven 3D camera flight powered by `Lenis` and lerped `requestAnimationFrame` interpolation across 5 distinct stages (Overview, Engineering Directive, Production Arsenal, 5D Computational Stack, and Tactical Uplink).
- **Procedural Superformula 3D Plush Envelope (`ThreePlushEnvelope`)**: Custom WebGL/Three.js superformula geometry with Hooke's Law damped harmonic spring physics, scroll hop mechanics, pointer tilt attraction, and interactive mailbox slot dispatch.
- **Multi-Scale Procedural Cartographic Canvas (`MosaicMap`)**: Zero-image, DPR-aware HTML5 Canvas GeoJSON rendering engine with antimeridian geometry sanitization and smooth multi-stage camera interpolation (Global Continents $\rightarrow$ All India & 36 States/UTs $\rightarrow$ South India Engineering Corridors).
- **Native Web Audio Synthesizer (`audio.js`)**: Zero-latency procedural Web Audio API sound effects (quantum clock ticks, pneumatic airlock releases, gravitational sub-bass pulses, and cathedral organ synthesis) paired with persistent background soundtrack controls.
- **Instant First Contentful Paint**: Route-level and WebGL component code-splitting via `React.lazy` & `Suspense`.

6. **Clinova Health Care (CMS)** — Enterprise clinical platform with 5-tier zero-trust RBAC, atomic slot locks, and vector pathology reports.
7. **AniLearn 日本語** — Gamified Japanese mastery platform with `< 50ms` in-browser Web Speech phonetic grading.
